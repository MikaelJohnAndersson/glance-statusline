Status line cheat sheet

What each symbol on the Claude Code status line means. The third row is off until you run /glance:detail. Anything without data is left out, so a row may show fewer parts than this.

 my-app /  main / e70fed6 | ↑2 ●3 ✚9 ?1 +212 −47  02:31 |   Opus 5.5 |  58%  3m | 5h 41%  1h51 | 7d 23%  4d4h  116k/200k r 110k w 4k i 2k o 1k ▂▃▅▆ |  hit 94% miss 1 |  5h 1h51 04:43 7d 4d4h Tue 06:51 | $1.84  23m api 7m

Row 1 — the repo

 my-appThe folder Claude Code is working in.
 mainCurrent branch. ⌘-click opens its pull request, or the branch on GitHub when it has none.
e70fed6Short hash of HEAD. ⌘-click opens the commit on GitHub. On a detached HEAD the branch is left out.
↑2 ↓1Commits ahead of / behind the upstream branch.
●3Files staged for commit.
✚9Files changed but not staged.
?1Untracked files.
≡2Stash entries.
+212 −47Lines Claude added / removed this session (not the git diff).
 02:31Clock, pinned to the right with the  beside it. Both are dropped together when the row has no room for them.
⌘-click opens this page.

Row 2 — Claude at a glance

 OpusOpus — a music note (an opus is a musical work).
 SonnetSonnet — a pencil.
 HaikuHaiku — a leaf.
 FableFable — an open book.
✦ otherAny other model.
 58%Context window used. green below 60%, amber from 60%, red from 85%.
 …Waiting for Claude Code’s first numbers, sent with the session’s first reply. Before then, context and the limits show their last known values in grey.
 3mPrompt cache is warm, and goes cold in 3 minutes.
 coldCache has expired: the next message re-processes the whole conversation, which is slower and uses more of your limit.
5h 41%5-hour usage limit used. ⌘-click opens your usage page on claude.ai. Pro/Max only, after the first reply.
 1h51Time until the limit before it resets: after 5h, the 5-hour window; after 7d, the week.
7d 23%7-day limit. ⌘-click opens the usage page.

Row 3 — detail, toggled with /glance:detail

/glance:detailTurns this row on or off. It shows on the next refresh, within 30 s.
 116k/200kTokens in the context, out of the window’s size.
r 110k w 4kOf the last request’s input: read from the cache (cheap), written to the cache.
i 2k o 1kFresh input, not cached, and the reply’s output tokens.
▁▂▃▅▆Context % over the session’s last 8 changes. A drop is a compaction or /clear.
 hit 94%Share of this session’s input read from the cache. Higher is cheaper and faster.
miss 1 (ttl_expired_5m)Requests that re-processed what the cache already held, and the likely cause of the last one.
 5h 1h51 04:43Time until each limit resets, and the clock time it happens. 7d shows the weekday too.
$1.84Estimated session cost at list price. Not your bill; resets on /clear.
 23m api 7mHow long the session has run, and how much of that was spent waiting on the API.

Behind it

Pluginglance. /glance:setup points your statusLine setting at the script, /glance:remove takes it out again.
FilesThe script, this page and the state below live in the plugin’s data folder, ~/.claude/plugins/data/glance-glance-statusline/. Each session copies the installed version there.
RefreshOn each reply, and every 30 s while idle (refreshInterval).
HistoryContext readings for the sparkline, one file per session in history/, deleted after 7 days. The last known limits are in limits.
NarrowEach row drops detail until it fits. Row 1: the clock and the help icon. Row 2: the model’s name (its icon stays), the 7d reset time, 7d, the 5h reset time, cache. Row 3: the miss cause, API time, reset clock times, the token breakdown, the sparkline, session time, the window size, the cache group, the resets.
FontIcons need a Nerd Font in your terminal. If this page shows boxes, that font isn’t available to the browser.
